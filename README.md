# Tessar Web

Website giới thiệu framework Tessar, xây dựng bằng Next.js App Router.

## Bắt đầu

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Các lệnh kiểm tra: `pnpm lint`, `pnpm exec tsc --noEmit`, `pnpm build`.

## Dự án

- Đọc [AGENTS.md](AGENTS.md) trước khi sửa code.
- Cấu trúc app và hướng mở rộng nằm trong [docs/architecture.md](docs/architecture.md).
- Logo và hướng dẫn dùng brand nằm trong [public/brand/tessar/README.md](public/brand/tessar/README.md).
- Màu sắc và typography của app nằm trong [app/tokens.css](app/tokens.css).
- Font IBM Plex và giấy phép nằm trong `public/fonts/`.

Không thêm framework docs, xác thực hoặc playground trước khi có yêu cầu tính năng cụ thể.
